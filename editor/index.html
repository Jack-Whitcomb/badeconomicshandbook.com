Editor

To save changes, this editor needs a GitHub token that can edit the website's repository. You only do this once per browser.

  1. Open GitHub’s new-token page (signed in as Jack-Whitcomb).
  2. Give it any name. Under Repository access, pick Only select repositories and choose badeconomicshandbook.com.
  3. Under Permissions → Repository permissions, set Contents to Read and write, and Actions to Read-only (so the editor can tell you when the site has updated).
  4. Click Generate token, copy it, and paste it here.

The token is kept only in this browser. Sign out from the editor’s sidebar to remove it.
